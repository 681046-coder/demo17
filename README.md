# ระบบคลังสินค้าคอมพิวเตอร์ (C + เว็บ)

เซิร์ฟเวอร์เขียนด้วยภาษา C ล้วน (`server.c`) ไม่พึ่งไลบรารีภายนอก หน้าเว็บคือ `index.html` ที่เซิร์ฟเวอร์ส่งให้เอง

## วิธีรัน
```
make run          # แล้วเปิด http://localhost:8080
./inventory 3000  # เปลี่ยนพอร์ต
```
ข้อมูลเก็บในไฟล์ `data.csv` (สร้างอัตโนมัติ)

## ฟีเจอร์
- แสดงสินค้าทั้งหมดบนเว็บ พร้อมแถบระดับสต็อกและสถานะ ปกติ / ใกล้หมด / หมด
- นำเข้า และ นำออก (นำออกเกินสต็อกไม่ได้)
- แจ้งเตือนเมื่อสินค้าเหลือถึงจุดเตือนหรือหมด ทั้งแบนเนอร์ในหน้าเว็บ ป๊อปอัปมุมจอ การแจ้งเตือนของเบราว์เซอร์ และบรรทัด `[แจ้งเตือน]` ในเทอร์มินัลของเซิร์ฟเวอร์
- หน้าเว็บรีเฟรชข้อมูลเองทุก 5 วินาที

## API
| เมธอด | พาธ | พารามิเตอร์ |
|---|---|---|
| GET | `/api/items` | |
| POST | `/api/add` | `name, cat, qty, min` |
| POST | `/api/in` | `id, qty` |
| POST | `/api/out` | `id, qty` |
| POST | `/api/del` | `id` |

## ใช้กับ GitHub
- `git init && git add . && git commit -m "init" && git push` ขึ้น repo ได้เลย โฟลเดอร์ `.github/workflows` จะคอมไพล์และทดสอบให้ทุกครั้งที่ push
- GitHub Pages รันโปรแกรม C ฝั่งเซิร์ฟเวอร์ไม่ได้ ถ้าจะลองรัน ให้เปิด **Codespaces** แล้วสั่ง `make run` (GitHub จะ forward พอร์ต 8080 ให้) หรือนำไปรันบนเครื่อง/โฮสต์ที่รองรับ Docker

## ข้อควรระวัง
ยังไม่มีระบบล็อกอิน ใช้ภายในเครือข่ายที่ไว้ใจได้ หรือวางหลัง reverse proxy ที่มีการยืนยันตัวตน
